# Blog Post Images

This folder contains featured images for blog posts displayed throughout the site.

## Required Images

Place the following images in this folder with these exact names:

- `agentic-ai-ambient-computing.png` - Featured image for "How Agentic AI, Spatial & Ambient Computing Are Reshaping Tech"
- `how-to-build-mvp-and-attract-fund-2025.png` - Featured image for "How to Build a Minimum Viable Product (MVP) and Attract…"
- `mlops-backbone-of-modern-ml-apps.png` - Featured image for "MLOps: The Backbone of Modern Machine Learning Applications"

## Image Format

- Format: PNG or JPG
- Recommended dimensions: 1200x630px (1.91:1 aspect ratio) - optimal for social sharing
- File size: Keep under 300KB for optimal performance
- Quality: High quality images that represent the blog post content

## Usage

These images are referenced in `/data/blog.ts` and displayed in:
- Blog section on the homepage
- Blog listing page
- Individual blog post detail pages

## Adding New Blog Posts

When adding new blog posts, add the corresponding featured image file here with the same name as the blog post slug.

# Achievements Images

This folder contains achievement badges and certification images displayed in the Achievements section.

## Required Images

Place the following images in this folder with these exact names:

- `top-developer.png` - Top Developer badge (recommended size: 180x120px)
- `quality-badge.png` - Quality Badge (recommended size: 180x120px)
- `innovation.png` - Innovation Award (recommended size: 180x120px)
- `excellence.png` - Excellence badge (recommended size: 180x120px)

## Image Format

- Format: PNG (with transparency preferred) or JPG
- Recommended dimensions: 180x120px
- Aspect ratio: 3:2
- File size: Keep under 200KB for optimal performance

## Usage

These images are referenced in `/data/achievements.ts` and displayed in the `AchievementsSection` component.

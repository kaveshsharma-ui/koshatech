# Partner/Client Logos

This folder contains partner and client logo images displayed in the Achievements section.

## Required Images

Place the following images in this folder with these exact names:

- `partner-1.png` - Partner/Client logo 1 (recommended size: 160x80px)
- `partner-2.png` - Partner/Client logo 2 (recommended size: 160x80px)
- `partner-3.png` - Partner/Client logo 3 (recommended size: 160x80px)
- `partner-4.png` - Partner/Client logo 4 (recommended size: 160x80px)
- `partner-5.png` - Partner/Client logo 5 (recommended size: 160x80px)

## Image Format

- Format: PNG (with transparency preferred) or JPG
- Recommended dimensions: 160x80px
- Aspect ratio: 2:1
- File size: Keep under 100KB for optimal performance
- Background: Transparent or white background preferred

## Usage

These images are referenced in `/data/achievements.ts` and displayed in the `AchievementsSection` component. They will appear in grayscale with reduced opacity and become fully visible on hover.
